# Publish the static dashboard

`index.html` is the static-site entry point. It embeds the analysis results and works without a server, backend, or third-party JavaScript libraries.

## GitHub Pages

1. Create or choose a GitHub repository and add the contents of this project folder to its root.
2. Push the files to the repository's default branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
5. After GitHub Pages publishes the site, use the URL shown in the Pages settings. The dashboard is the repository root's `index.html`.

The source data and analysis files are included in this project folder. Review the repository visibility before publishing; GitHub Pages content is public for public repositories. Do not publish private or sensitive data.

This project is prepared for deployment, but it has not been uploaded or published to a hosting provider.
