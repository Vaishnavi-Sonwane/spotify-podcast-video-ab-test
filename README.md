# Podcast Video-First Discovery Feed Experiment

An end-to-end product analytics case study using Python, SQLite SQL, statistical tests, and an interactive dashboard.

## Dashboard

Open the GitHub Pages dashboard at `https://vaishnavi-sonwane.github.io/spotify-podcast-video-ab-test/` after Pages finishes publishing.

## Finding

Treatment increased podcast listening by 1.08 minutes per user per day (+10.4%, 95% CI 0.21 to 1.94, p = 0.0149). App crashes increased 18.8% and breached the experiment guardrail. Recommendation: iterate before launch. This is simulated training data, not an official Spotify experiment.
